============================================================
1) TONG QUAN DU AN
============================================================

1.1 Muc dich he thong
- Day la he thong quan tri sinh vien tong hop, ket hop:
	+ Quan ly ho so sinh vien, lop, hoc ky, mon hoc.
	+ Quan ly chuong trinh dao tao (curriculum) theo khoa/nganh/hoc ky.
	+ Quan ly diem, hoc phi, thanh toan VNPay.
	+ Diem danh QR (co quy trinh session + check-in).
	+ Danh gia diem ren luyen (DRL) + minh chung + quy trinh duyet.
	+ He thong e-learning (course, lesson, assignment, exam, registration).
	+ Bo phan "Mot cua" cho thu tuc hanh chinh sinh vien.

1.2 Doi tuong su dung
- QTV (quan tri vien): full admin.
- LECTURER (giang vien): quan ly day hoc, diem, lich day.
- BCH: role can bo lop/ho tro DRL va van hanh mot so phan he.
- STUDENT: tu phuc vu hoc vu, hoc phi, DRL, e-learning, thong bao.

1.3 Flow hoat dong chinh (macro)
- User login -> nhan cookie session + csrf token.
- Frontend goi /auth/me de khoi tao state xac thuc.
- Dieu huong route theo role (RoleRoute + Sidebar role-based menu).
- Moi phan he goi API /api/* theo nganh doc lap:
	+ /students, /classes, /semesters, /academic, /curriculum
	+ /attendance, /training, /evidence
	+ /elearning
	+ /finance, /payments
	+ /services
- DB MySQL duoc truy cap qua Prisma (co layer proxy de map naming).

1.4 Kien truc tong the
- Kieu kien truc: Monorepo 2 app chinh.
	+ frontend/: React + Vite + Tailwind + Zustand.
	+ backend/: Express + Prisma + MySQL.
- Pattern: REST API, role-based authorization, cookie-based auth + CSRF.
- Khong co microservices, khong co message broker; logic tap trung trong 1 API server.

So do text (tong quan):

[Browser/Capacitor App]
		-> Axios (withCredentials + CSRF header)
		-> /api/* (Express)
		-> Middleware: CORS -> security headers -> compression -> JSON -> cookies -> CSRF
		-> Route -> Controller -> Prisma Client Proxy -> MySQL
		-> Response JSON / file stream

8) SECURITY
============================================================

8.1 JWT/session
- JWT cookie session (`qlsv_session`) + token fallback header/query.
- Cookie options co sameSite, secure, domain handling.

8.2 Encrypt/hash
- Password: bcrypt.
- Du lieu nhay cam student (birthday, gender, id_card, hometown, address): AES-256-CBC trong `utils/crypto.ts`.

8.3 Rate limit
- Chua thay middleware rate limit (express-rate-limit).

8.4 CSRF/XSS/SQL injection protection
- CSRF:
	+ cookie token + header x-csrf-token + middleware.
- XSS:
	+ chua thay explicit sanitizer layer server-side.
- SQLi:
	+ Prisma an toan phan lon.
	+ co `queryRawUnsafe` trong timetable => can review nguy co injection (du dang dung params array, nhung van la diem can than trong).

8.5 Permission system
- roleMiddleware per route, role set: QTV/LECTURER/BCH/STUDENT.
- Frontend RoleRoute chi la UX guard, backend moi la enforcement that su.

8.6 Security best practices
Diem tot:
- Cookie httpOnly/secure/sameSite handling ky.
- CSRF implementation co retry token flow.
- Co audit log cho hanh vi quan trong.

Rui ro:
- JWT_SECRET fallback 'secret' neu env thieu.
- ENCRYPTION_KEY fallback hardcoded.
- Console log nhieu (co the lo thong tin).
- Chua co rate limit + brute-force protection.
